# Pasta preparada para ícones inspirados no renzu_customs

Este diretório foi criado para você colocar manualmente os SVGs/PNGs que deseja reaproveitar visualmente no novo `qbx_customs`, **sem copiar os assets automaticamente neste patch**.

## Origem esperada
Se você quiser usar os mesmos ícones visuais do `renzu_customs`, copie apenas os arquivos desejados de:

- `renzu_customs/html/img/`

para:

- `qbx_customs/web/assets/renzu-icons/`

## Nomes já preparados pela nova NUI
A interface nova tenta carregar estes nomes automaticamente quando existirem:

- `Accessories.svg`
- `BikeWheel.svg`
- `WheelType.svg`
- `custom_engine.svg`
- `custom_turbo.svg`
- `extra.svg`
- `headlight.svg`
- `motor.svg`
- `neon.svg`
- `plate.svg`
- `window.svg`
- `xenon.svg`
- `0.svg` até `49.svg` para mods por ID quando configurados
- `48.svg` para livery

## Observação
Se os arquivos não forem colocados aqui, a NUI usa automaticamente o fallback textual/ícone interno já existente.
